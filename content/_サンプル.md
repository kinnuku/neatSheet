> <strong>CASE とは？</strong>
> 条件によって返す値を切り替える式です。Excel の IF 関数のようなものです。
>
> <strong>IIF とは？</strong>
> 条件が1つだけのときに使える、CASE の短縮形です。

### １．使い方

`CASE` は上から順に条件を調べ、最初に当てはまった `THEN` の値を返します。
どれにも当てはまらないときは `ELSE` の値になります（`ELSE` を省略すると `NULL`）。

```sql
CASE
	WHEN 条件1 THEN 値1
	WHEN 条件2 THEN 値2
	ELSE それ以外の値
END

IIF(条件, 当てはまるときの値, 当てはまらないときの値)
```

### ２．実践例

以下のような `SCORE` テーブルの点数を、評価に変換したいとします。

| 社員名 | 点数 |
| --- | --- |
| 佐藤 | 100 |
| 鈴木 | 72 |
| 高橋 | 45 |

```sql
SELECT
	社員名
	,点数
	,CASE
		WHEN 点数 >= 90 THEN 'A'
		WHEN 点数 >= 60 THEN 'B'
		ELSE 'C'
	END AS 評価
	,IIF(点数 >= 60, '合格', '不合格') AS 判定
FROM SCORE

-- → 佐藤 100 A 合格
-- → 鈴木 72  B 合格
-- → 高橋 45  C 不合格
```

#### 注意点

- 条件は<strong>上から順に</strong>判定されるので、範囲が広い条件を先に書くと、後ろの条件に届きません
- `点数` が `NULL` の行は、どの `WHEN` にも当てはまらず `ELSE` の値になります
- 詳しくは [NULL と三値論理](<../06_基礎知識/02_NULL と三値論理.md>) を参照
