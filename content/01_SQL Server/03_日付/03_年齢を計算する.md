# 年齢を計算する
キーワード: DATEDIFF + CASE

> 本ページでは、指定した日に対して、年齢を計算する方法を解説します。

### １．使い方

```sql
,DATEDIFF(year, 誕生日, GETDATE()) -
			CASE
				WHEN DATEADD(year, DATEDIFF(year, 誕生日, GETDATE()), 誕生日) > GETDATE() THEN 1
				ELSE 0
			END AS [年齢]
```

少し複雑になっていますが、以下のみだと、**単純に「年」の値の差**を返すだけで、月日を考慮できていません。

```sql
DATEDIFF(year, birthday, GETDATE()) 
```

例えば、誕生日が `1998-08-07`、今日が `2026-07-01` の場合、実際にはこの人はまだ27歳（誕生日が来ていない）なので、これは不正確です。

```sql
DATEDIFF(year, '1998-08-07', '2026-07-01') = 28
-- ← まだ誕生日前で27歳なのに28と出てしまう
```

そこで、CASE文の補正が必要になってきます。
この部分で「今年の誕生日」を計算し、それが今日より**未来**なら「まだ誕生日を迎えていない」と判定して `1` を引く、という仕組みです。

```sql
DATEADD(year, DATEDIFF(year, birthday, GETDATE()), birthday) > GETDATE()
```

<strong>【補足】</strong>
閏年生まれ（2/29）の場合も、SQL Serverの `DATEADD` が自動的に2/28に丸めてくれるので、実用上は問題なく動作します。
