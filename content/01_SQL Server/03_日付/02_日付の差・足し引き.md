# 日付の差・足し引き
キーワード: DATEDIFF / DATEADD

> <strong>DATEDIFF()とは？</strong>
> 2つの日付（または時刻）の差分を指定した単位（年、月、日、時間など）で計算するための関数です。
>
> <strong>DATEADD()とは？</strong>
> 指定した日付（または時刻）に指定した単位（年、月、日、時間など）を加算（または減算）し、算出するための関数です。

### １．DATEDIFF

```sql
DATEDIFF(datepart, start_date, end_date)

-- 日数の差
DATEDIFF(day, '2026-01-01', '2026-06-15')    -- → 165

-- 月数の差
DATEDIFF(month, '2026-01-01', '2026-06-15')  -- → 5

-- 年数の差
DATEDIFF(year, '1990-04-01', '2026-06-15')   -- → 36
```

### ２．DATEADD

```sql
DATEADD(datepart, number, date)

-- 30日後
DATEADD(day, 30, '2026-06-15')    -- → 2026-07-15

-- 3ヶ月前
DATEADD(month, -3, '2026-06-15')  -- → 2026-03-15

-- 1年後
DATEADD(year, 1, '2026-06-15')    -- → 2027-06-15
```

### ３．datepart（単位）一覧

| datepart | **意味** |
| --- | --- |
| `year` | 年 |
| `month` | 月 |
| `day` | 日 |
| `hour` | 時 |
| `minute` | 分 |
| `second` | 秒 |
