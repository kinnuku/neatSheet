# データがあるか確かめる
キーワード: EXISTS / NOT EXISTS

> <strong>EXISTSとは？NOT EXISTSとは？</strong>
>
> 「○○が存在するか、しないか」を判定できる関数です。
> ※より正確に言うと、サブクエリが1行以上のレコードを返すか？サブクエリが0行か？

### １．実践例

以下のように顧客テーブルと注文テーブルがあったとします。

<strong>顧客テーブル（Customers）</strong>

| CustomerID | CustomerName |
| --- | --- |
| 1 | 山田 |
| 2 | 佐藤 |
| 3 | 鈴木 |
| 4 | 田中 |

<strong>注文テーブル（Orders）</strong>

| OrderID | CustomerID | Price |
| --- | --- | --- |
| 1 | 1 | 12,000 |
| 2 | 1 | 14,000 |
| 3 | 4 | 11,000 |

この場合、顧客の注文有無は、以下ということが分かりますが、これをクエリで表現します。
<strong>注文がある顧客：</strong>山田、田中
<strong>注文がない顧客：</strong>佐藤、鈴木

### ２．EXISTS：条件に合致するデータが存在する

```sql
SELECT C.CustomerID, C.CustomerName
FROM Customers AS C
WHERE EXISTS (
    SELECT 1
    FROM Orders AS O
    WHERE O.CustomerID = C.CustomerID
)
```

### ３．NOT EXISTS：条件に合致するデータが存在しない

```sql
SELECT C.CustomerID, C.CustomerName
FROM Customers AS C
WHERE NOT EXISTS (
    SELECT 1
    FROM Orders AS O
    WHERE O.CustomerID = C.CustomerID
)
```
