# 文字を切り出す
キーワード: LEFT / RIGHT / SUBSTRING

> <strong>LEFT()とは？</strong>
> 文字列の**左端**から、指定した長さの文字を切り出すための関数です。
>
> <strong>RIGHT()とは？</strong>
> 文字列の**右端**から、指定した長さの文字を切り出すための関数です。
>
> <strong>SUBSTRING()とは？</strong>
> 文字列の**任意の位置**から、指定した長さの文字を切り出すための関数です。

### １．使い方

```sql
LEFT(対象の文字列, 切り取る長さ)
RIGHT(対象の文字列, 切り取る長さ)
SUBSTRING(対象の文字列, 開始位置, 切り取る長さ)

LEFT('123456789', 4)
-- → 1234

RIGHT('123456789', 3)
-- → 789

SUBSTRING('123456789', 4, 4)
-- → 4567
```
