# 文字の位置を探す
キーワード: CHARINDEX

> <strong>CHARINDEX()とは？</strong>
> 文字列の中から特定の文字を検索し、最初に見つかった位置を返す関数です。
> ※先頭文字が1です。

### １．使い方

```sql
CHARINDEX(検索文字, 検索対象の文字列, [検索開始位置])

CHARINDEX('World', 'World Hello World')
-- → 1

CHARINDEX('World', 'World Hello World', 2)
-- → 13（2文字目以降で、Worldを探すので、先頭のWorldは除外される）
```

他にも文字列に<strong>`「@」`</strong>が含まれるかで、メールアドレスかどうかの判定にも使える。

```sql
,IIF(CHARINDEX('@', 'abc12345@gmail.com') > 0, 'メアド有', 'メアド無') AS メアド有無
-- → メアド有
```
