# 文字を置き換える
キーワード: REPLACE

> <strong>REPLACE()とは？</strong>
> 文字列の中から特定の文字や単語を検索し、別の文字に置換する関数です。

### １．使い方

```sql
REPLACE(対象文字列, 検索文字列, 置換文字列)

-- 電話番号
REPLACE('090-1234-5678', '-', '')
-- → 09012345678

-- 複数の文字列を置換する場合は、段差を付けると見やすくなります。
SELECT
    REPLACE(
        REPLACE(
            REPLACE('(090) 1234 5678'
                , ')', ''   -- 括弧除去
            )
        , ' ', ''           -- スペース除去
        )
    , '(', ''               -- 括弧除去
    )
-- → 09012345678
```
