# 前後の行の値を取る
キーワード: LAG / LEAD

> <strong>LAG()とは？</strong>
> SQLのウィンドウ関数の1つで、現在の行より**前の行の値**を取得できます。
>
> <strong>LEAD()とは？</strong>
> SQLのウィンドウ関数の1つで、現在の行より**後の行の値**を取得できます。

### １．基本的な使用方法

`PARTITION BY` と `ORDER BY` は任意ですが、基本的に使用するので、合わせて覚えましょう。

- `[指定位置]` <strong>： 何行前（後）のデータを取得するか（省略した場合は 1）</strong>
- `[戻り値]` <strong>： NULL だった場合に、返す値（省略した場合は NULL）</strong>

```sql
,LAG(取得したい列名 , [指定位置] , [戻り値]) OVER(
	PARTITION BY [グループ化したい列名 1], [グループ化したい列名 2], ...
	ORDER BY [並び替えしたい列名 1] (ASC | DESC), [並び替えしたい列名 2] (ASC | DESC),...
) AS LAG

,LEAD(取得したい列名 , [指定位置] , [戻り値]) OVER(
	PARTITION BY [グループ化したい列名 1], [グループ化したい列名 2], ...
	ORDER BY [並び替えしたい列名 1] (ASC | DESC), [並び替えしたい列名 2] (ASC | DESC),...
) AS LEAD
```

### ２．実践例

以下のような `SALES` テーブルに、前月、前々月、翌月、翌々月の売上を紐づけたいとする。

| **社員名** | **売上月** | <strong>売上[万円]</strong> |
| --- | --- | --- |
| 佐藤 | 2026-01 | 100 |
| 佐藤 | 2026-02 | 120 |
| 佐藤 | 2026-03 | 110 |
| 佐藤 | 2026-04 | 150 |
| 佐藤 | 2026-05 | 75 |
| 鈴木 | 2026-01 | 80 |
| 鈴木 | 2026-02 | 90 |
| 鈴木 | 2026-03 | 95 |
| 鈴木 | 2026-04 | 100 |
| 鈴木 | 2026-05 | 140 |

それでは、実際にコードを書いてみます。

```sql
SELECT
	社員名
	,売上月
	,LAG(売上, 2, 0) OVER( PARTITION BY 社員名 ORDER BY 売上月 ASC) AS 前々月売上
	,LAG(売上, 1, 0) OVER( PARTITION BY 社員名 ORDER BY 売上月 ASC) AS 前月売上
	,売上
	,LEAD(売上, 1) OVER( PARTITION BY 社員名 ORDER BY 売上月 ASC) AS 翌月売上
	,LEAD(売上, 2) OVER( PARTITION BY 社員名 ORDER BY 売上月 ASC) AS 翌々月売上
FROM SALES
```

出力結果は以下のようになります。
前月・翌月の場合は、`[指定位置]` は不要ですが、あえて記載しています。
また、`[戻り値]` を指定した部分のみ `0` になり、それ以外は  `NULL` になっています。

| **社員名** | **売上月** | **前々月売上** | **前月売上** | **売上** | **翌月売上** | **翌々月売上** |
| --- | --- | --- | --- | --- | --- | --- |
| 佐藤 | 2026-01 | 0 | 0 | 100 | 120 | 110 |
| 佐藤 | 2026-02 | 0 | 100 | 120 | 110 | 150 |
| 佐藤 | 2026-03 | 100 | 120 | 110 | 150 | 75 |
| 佐藤 | 2026-04 | 120 | 110 | 150 | 75 | NULL |
| 佐藤 | 2026-05 | 110 | 150 | 75 | NULL | NULL |
| 鈴木 | 2026-01 | 0 | 0 | 80 | 90 | 95 |
| 鈴木 | 2026-02 | 0 | 80 | 90 | 95 | 100 |
| 鈴木 | 2026-03 | 80 | 90 | 95 | 100 | 140 |
| 鈴木 | 2026-04 | 90 | 95 | 100 | 140 | NULL |
| 鈴木 | 2026-05 | 95 | 100 | 140 | NULL | NULL |
