# 連番を振る
キーワード: ROW_NUMBER

> <strong>ROW_NUMBER()とは？</strong>
> SQLのウィンドウ関数の1つで、データセットの各行に一意の連番（行番号）を付与するときに使用します。

### １．基本的な使用方法

`PARTITION BY` と `ORDER BY` は任意ですが、基本的に使用するので、合わせて覚えましょう。

```sql
,ROW_NUMBER() OVER(
	PARTITION BY [グループ化したい列名 1], [グループ化したい列名 2], ...
	ORDER BY [並び替えしたい列名 1] (ASC | DESC), [並び替えしたい列名 2] (ASC | DESC),...
) AS RN
```

### ２．実践例

以下のような `SCORE` テーブルに、人ごとに教科関係なく最高点の教科を表示したいとする。
その場合に `ROW_NUMBER()`  を使って、番号を振れば、いい感じに出力できます。

| 9 | 鈴木 一郎 | 0003 | 英語 | C001 | 88 |

今回の目的は、**人ごとに教科関係なく最高点の教科を表示する**ことなので、 `PARTITION BY` と `ORDER BY` はそれぞれ以下のようになります。

<strong>※PARTITION BY でuser_nameを使用してもいいですが、同姓同名がいる場合もあるので、user_idを使用するほうがエラーが起きにくいです。</strong>

**◆PARTITION BY**

- user_id

**◆ORDER BY**

- score

それでは、実際にコードを書いてみます。

```sql
SELECT
	id
	,user_name
	,user_id
	,subject_name
	,subject_id
	,score
	,ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY score DESC) AS RN
FROM SCORE
```

これを出力すると、以下になります。

先程、**人ごとに教科関係なく最高点順に番号を振った**ので、`WHERE句` でその番号を使えば、欲しい情報だけを表示できます。

```sql
SELECT
	id
	,user_name
	,user_id
	,subject_name
	,subject_id
	,score
	,RN
FROM(	
	SELECT
		id
		,user_name
		,user_id
		,subject_name
		,subject_id
		,score
		,ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY score DESC) AS RN
	FROM SCORE
) AS A
WHERE
	RN = 1
```

これを出力すると、以下になります。

| id | user_name | user_id | subject_name | subject_id | score | RN |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 山田 太郎 | 0001 | 国語 | A001 | 100 | 1 |
| 8 | 佐藤 二郎 | 0002 | 英語 | C001 | 90 | 1 |
| 9 | 鈴木 一郎 | 0003 | 英語 | C001 | 88 | 1 |
