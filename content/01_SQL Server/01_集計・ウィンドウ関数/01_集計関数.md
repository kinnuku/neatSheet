# 集計関数
キーワード: COUNT / AVG / SUM / MAX / MIN

> <strong>COUNT()とは？</strong>
> 指定した条件に一致するデータの**件数**を取得する集計関数です。
>
> <strong>AVG()とは？</strong>
> 指定した条件に一致する数値列の**平均値**を計算する集計関数です。
>
> <strong>SUM()とは？</strong>
> 指定した条件に一致する数値列の**合計値**を計算する集計関数です。
>
> <strong>MAX()とは？</strong>
> 指定した条件に一致する数値列の**最大値**を計算する集計関数です。
>
> <strong>MIN()とは？</strong>
> 指定した条件に一致する数値列の**最小値**を計算する集計関数です。

### １．実践例

以下のような `SCORE` テーブルがあるとします。

| **社員名** | **部署名** | **年齢** | **点数** |
| --- | --- | --- | --- |
| 佐藤 | 営業 | 48 | 100 |
| 鈴木 | 人事 | 36 | 88 |
| 高橋 | システム | 24 | 45 |
| 田中 | 総務 | 42 | 98 |
| 伊藤 | 人事 | 26 | 65 |
| 渡辺 | 総務 | 32 | 70 |
| 山本 | システム | 28 | 82 |
| 中村 | 総務 | 36 | 90 |
| 小林 | システム | 28 | 66 |
| 加藤 | システム | 34 | NULL |

それぞれの使い方は、いたってシンプルで以下の通りです。
※集計したい条件の列に `NULL` が含まれる場合は、 `NULL` を除いて集計します。

また、集計の条件を `*` にできるのは、 `COUNT` だけです。
理由は、 `COUNT` 以外はどこかの列の合計や最大値を集計するので、`必ず`列を指定する必要があります。

```sql
SELECT
	COUNT(*)
	,COUNT(点数)
	,AVG(年齢)
	,SUM(点数)
	,MAX(点数)
	,MIN(点数)
FROM SCORE

-- → 10    COUNT（NULL を含めて数える）
-- → 9     COUNT（NULL を除いて数える）
-- → 33    AVG（整数の列なので小数点以下は切り捨て）
-- → 704   SUM
-- → 100   MAX
-- → 45    MIN
```

> <strong>AVG の注意</strong>
> 年齢のような整数型の列を `AVG` すると、結果も整数になります（33.4 → 33）。
> 小数まで出したいときは、`AVG(年齢 * 1.0)` のように小数型にしてから平均します（→ 33.4）。

集計関数のみでも使用できますが、大体は `GROUP BY`  も一緒に使います。
※`GROUP BY`  するのは、**集計関数以外の列名全部**です。

```sql
SELECT
	部署名
	,COUNT(*)
FROM SCORE

GROUP BY
	部署名
	
	
	/*
  営業 1
  人事 2
  システム 4
  総務 3
*/
```

### ２．質問

<strong>■質問①</strong>：こんな書き方はあり得ますか？（部署ごとの人数を数えたい）

```sql
SELECT
	部署名
	,COUNT(点数)
FROM SCORE
GROUP BY 部署名, 点数
```

→ SQL としてはエラーにならずに動きますが、<strong>目的とは違う結果</strong>になります。
`GROUP BY 部署名, 点数` だと「部署 × 点数」の組み合わせごとに数えるので、同じ部署で同じ点数の人がいない限り、ほぼすべて 1 件ずつになってしまいます。
`GROUP BY` に書くのは集計関数以外の列だけなので、今回は `部署名` だけで OK です。

部署ごとの<strong>人数</strong>を数えたい場合は `COUNT(*)` を使います。
`COUNT(点数)` のように列名を指定すると `NULL` を除いて数えるので、点数が `NULL` の加藤さんが数えられません。

```sql
SELECT
	部署名
	,COUNT(*) AS 人数
FROM SCORE
GROUP BY 部署名

/*
  営業 1
  人事 2
  システム 4
  総務 3
*/
```

部署ごとに<strong>テストを受けた人数</strong>を数えたい場合は、`COUNT(点数)` で OK です。

```sql
SELECT
	部署名
	,COUNT(点数) AS 受験人数
FROM SCORE
GROUP BY 部署名

/*
  営業 1
  人事 2
  システム 3   ← 加藤さん（NULL）は数えない
  総務 3
*/
```
