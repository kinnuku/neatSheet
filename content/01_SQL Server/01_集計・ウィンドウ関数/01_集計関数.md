# 集計関数
キーワード: COUNT / AVG / SUM / MAX / MIN

> **COUNT()とは？**
> 行の**件数**を数える集計関数です。
>
> **AVG()とは？**
> 指定した数値列の**平均値**を計算する集計関数です。
>
> **SUM()とは？**
> 指定した数値列の**合計値**を計算する集計関数です。
>
> **MAX()とは？**
> 指定した列の**最大値**を取得する集計関数です。
>
> **MIN()とは？**
> 指定した列の**最小値**を取得する集計関数です。

### １．実践例

以下のような `SCORE` テーブルがあるとします。

| 社員名 | 部署名 | 年齢 | 点数 |
| --- | --- | --- | --- |
| 佐藤 | 営業 | 48 | 100 |
| 鈴木 | 人事 | 36 | 88 |
| 高橋 | システム | 24 | 45 |
| 田中 | 総務 | 42 | 98 |
| 伊藤 | 人事 | 26 | 65 |
| 渡辺 | 総務 | 32 | 70 |
| 山本 | システム | 28 | 82 |
| 中村 | 総務 | 36 | 90 |
| 小林 | システム | 28 | 66 |
| 加藤 | システム | 34 | NULL |

使い方はシンプルで、集計したい列名を `()` の中に書くだけです。

> **注意点**
> ・指定した列に `NULL` が含まれる場合、`NULL` の行は<strong>除いて</strong>集計されます。
> ・`()` の中に `*` を書けるのは `COUNT` だけです。`COUNT(*)` は `NULL` も含めて、行の数をそのまま数えます。
> ・`COUNT` 以外は「どの列の平均・合計・最大値・最小値なのか」を決める必要があるので、<strong>必ず</strong>列名を指定します。

```sql
SELECT
	COUNT(*)
	,COUNT(点数)
	,AVG(年齢)
	,SUM(点数)
	,MAX(点数)
	,MIN(点数)
FROM SCORE

-- → 10    COUNT(*)（NULL を含めて数える）
-- → 9     COUNT(点数)（NULL の加藤さんを除いて数える）
-- → 33    AVG（集計対象列なので小数点以下は切り捨て）
-- → 704   SUM
-- → 100   MAX
-- → 45    MIN
```

> **AVG の注意**
> ・年齢のような整数型の列を `AVG` すると、結果も整数になります。（33.4 → 33）
> ・小数まで出したいときは、`AVG(年齢 * 1.0)` のように小数型にしてから平均します。（→ 33.4）

集計関数は単体でも使えますが、多くの場合は `GROUP BY` と組み合わせて「〇〇ごと」に集計します。
`GROUP BY` には、<strong>SELECT に書いた列のうち、集計関数以外の列をすべて</strong>書きます。

```sql
SELECT
	部署名
	,COUNT(*) AS 人数
FROM SCORE
GROUP BY
	部署名

/*
  営業      1
  人事      2
  システム  4
  総務      3
*/
```

### ２．質問

**■質問①**：こんな書き方はあり得ますか？（部署ごとの人数を数えたい）

```sql
SELECT
	部署名
	,COUNT(点数)
FROM SCORE
GROUP BY 部署名, 点数
```

→ SQL としてはエラーにならずに動きますが、<strong>目的とは違う結果</strong>になります。
`GROUP BY 部署名, 点数` だと「部署 × 点数」の組み合わせごとに数えるので、同じ部署に同じ点数の人がいない限り、ほぼすべてが 1 件ずつになってしまいます。
`GROUP BY` に書くのは集計関数以外の列だけなので、今回は `部署名` だけで OK です。

部署ごとの<strong>人数</strong>を数えたい場合は `COUNT(*)` を使います（上の例と同じです）。
`COUNT(点数)` のように列名を指定すると `NULL` を除いて数えるので、点数が `NULL` の加藤さんが数に入りません。

部署ごとに<strong>テストを受けた人数</strong>を数えたい場合は、`COUNT(点数)` で OK です。

```sql
SELECT
	部署名
	,COUNT(点数) AS 受験人数
FROM SCORE
GROUP BY 部署名

/*
  営業      1
  人事      2
  システム  3   ← 加藤さん（NULL）は数えない
  総務      3
*/
```
