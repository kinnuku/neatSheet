# データ型の基本
キーワード: int / varchar / date

> 本ページでは、種類が多いデータ型の中から頻出のものを厳選し、要点を押さえて解説します。

### ０．はじめに

そもそもデータ型とは？
データ型とは、**データの「種類」と「扱い方」をコンピュータに伝えるためのルール**です。
例えば、 `42` という数字があったとき、データ型を指定することで、これが以下のどちらに当てはまるかを明確にすることができます。

- 数字の `42`（計算できる）
- 文字列の `"42"`（計算できない、テキストとして扱う）

では、なぜ「データ型」が必要なのか？

**① 正しく計算するため**

`100 + 200 = 300` は数値型なら正しく計算できますが、文字列型だと `"100" + "200" = "100200"` とくっついてしまいます。

**② 無駄なメモリを使わないため**

年齢（0〜150くらい）を保存するのに、`bigint`（8バイト）を使うのは無駄です。`tinyint`（1バイト）で十分。型を適切に選ぶことでDBのサイズや速度が変わります。

**③ データの品質を守るため**

「生年月日」カラムに `DATE` 型を指定しておけば、`"あいう"` や `99999` といった明らかにおかしな値を入れようとしたときにエラーにできます。

### 数値型

#### 整数型

| **型名** | **サイズ** | **範囲** | **主な用途** |
| --- | --- | --- | --- |
| `tinyint` | 1 byte | 0 〜 255 | フラグ、年齢 |
| `int` | 4 bytes | 約 ±21億 | 一般的なID・カウント |
| `bigint` | 8 bytes | 約 ±922京 | 大量データのID、集計値 |

#### 小数・浮動小数点型

| **型名** | **説明** | **主な用途** |
| --- | --- | --- |
| `decimal(p, s)` | 精度固定の小数。`p`=全桁数、`s`=小数点以下桁数 | 金額・財務データ（誤差NG） |
| `numeric(p, s)` | `decimal` と同義 | 同上 |
| `float(n)` | 浮動小数点（近似値） | 科学計算・センサーデータ |

`decimal`  の桁数を指定しない場合、`decimal(18, 0)` が適用されます。
※`numeric`  も同様です。

### 文字列型

#### 非Unicode（半角英数・ASCII）

| **型名** | **最大長** | **主な用途** |
| --- | --- | --- |
| `char(n)` | 8,000文字 | **固定長**。短い固定コード向け（例：都道府県コード） |
| `varchar(n)` | 8,000文字 | **可変長**。一般的なテキストに最適 |
| `varchar(max)` | 約2GB | 大量テキスト（非Unicode） |

<strong>■可変長のメリット</strong>

<strong>・容量の節約</strong>：短いデータは短いまま保持するため、記憶領域（メモリやストレージ）を無駄なく効率的に使える。
<strong>・柔軟性</strong>：文字数やデータ量が予測できない場合でも対応できる。

<strong>■可変長のデメリット</strong>

<strong>・処理速度の低下</strong>：データの区切り位置を毎回計算して判断する必要があるため、常に同じ長さで読み込める固定長に比べると処理に時間がかかる場合がある。
<strong>・管理の複雑さ</strong>：データの始まりと終わりをシステムが認識するための工夫（区切り文字など）が必要になる。

#### Unicode対応（日本語・多言語）

| **型名** | **最大長** | **主な用途** |
| --- | --- | --- |
| `nchar(n)` | 4,000文字 | 固定長Unicode |
| `nvarchar(n)` | 4,000文字 | **可変長Unicode。日本語テキストの標準** |
| `nvarchar(max)` | 約1GB | 大量テキスト（Unicode） |

※日本語を扱う場合は、`varchar` では文字化けや切り捨てが起きる場合があるので、必ず `nvarchar` にする。

### 日付・時刻型

| **型名** | **形式** | **主な用途** |
| --- | --- | --- |
| `date` | YYYY-MM-DD | 日付のみ |
| `time` | hh:mm:ss | 時刻のみ |
| `datetime` | YYYY-MM-DD hh:mm:ss[.mmm] | 日付 + 時刻 |
