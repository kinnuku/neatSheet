# 文字コードと改行
キーワード: CHAR(10) / CHAR(13)

> 本ページでは、よく使う文字コードを解説します。

### ０．はじめに

そもそも文字コードとは？
コンピュータは文字を直接扱えず、**すべて2進数（0と1の羅列）で扱います。
そのため「どの数値がどの文字に対応するか」を決めたルール（対応表）が必要になります。
これが文字コード**で**「文字」と「数値」を結びつける対応表（ルール）**のことです。

> 文字 'A' → 10進数：65 → 2進数：01000001
文字 'あ' → 10進数：12354 → 2進数：00110000 01000010
> 

### １．よく使う文字コード

| <strong>CHAR(n)</strong> | **意味** |
| --- | --- |
| `CHAR(9)` | タブ |
| `CHAR(10)` | 改行(LF) |
| `CHAR(13)` | 復帰(CR) |
| `CHAR(13) + CHAR(10)` | 改行(CRLF) |
| `CHAR(32)` | 半角スペース |
| `CHAR(0)` | NULL |
| `CHAR(160)` | ノーブレークスペース(NBSP) |

※ノーブレークスペースとは、Web上でコピペなどをした際の謎のスペースです。

<strong>（豆知識）改行に複数の表現方法がある理由</strong>

昔のタイプライターは、

- <strong>CR（Carriage Return）</strong>：印字ヘッドを行の先頭に戻す
- <strong>LF（Line Feed）</strong>：紙を1行分送る

という**別々の動作**でした。
この名残でOSによって改行の表現方法が分かれるのです。

- **Windows** → CR+LF（`\r\n`）＝ CHAR(13)+CHAR(10)
- <strong>Unix/Linux/macOS（現代）</strong> → LF（`\n`）のみ＝ CHAR(10)
- <strong>旧Mac OS（〜OS9）</strong> → CR（`\r`）のみ＝ CHAR(13)（今はほぼ見ない）
