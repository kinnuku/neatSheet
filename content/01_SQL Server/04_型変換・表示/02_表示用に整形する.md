# 表示用に整形する
キーワード: FORMAT

> <strong>FORMAT()とは？</strong>
> 数値や日付を「見た目用の文字列」に整形する関数です。
> ※戻り値は常に **NVARCHAR型** になります。

## 用途一覧

#### ① 日付の整形

```sql
SELECT FORMAT(GETDATE(), 'yyyy/MM/dd')         -- → 2026/07/01
SELECT FORMAT(GETDATE(), 'yyyy/M/d')           -- → 2026/7/1
SELECT FORMAT(GETDATE(), 'yyyyMMdd')           -- → 20260701
SELECT FORMAT(GETDATE(), 'yyyy年MM月dd日')      -- → 2026年07月01日
SELECT FORMAT(GETDATE(), 'HH:mm:ss')           -- → 14:35:00
SELECT FORMAT(GETDATE(), 'yyyy/MM/dd HH:mm')   -- → 2026/07/01 14:35
```

<strong>なぜMMとHHは大文字なのか？</strong>

月(Month)と分(minute)は英語の頭文字が同じ「M」で、大文字小文字で区別するルールになっているためです。

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `M`（大文字） | 月 | `MM` → 06 |
| `m`（小文字） | 分 | `mm` → 35 |

時刻についても同様に、24時間表記か12時間表記かで大文字小文字が変わります。

| 記号 | 意味 | 例（午後2時） |
| --- | --- | --- |
| `H`（大文字） | 24時間表記 | `HH` → 14 |
| `h`（小文字） | 12時間表記 | `hh` → 02（AM/PMを表す`tt`と併用が必要） |

```sql
SELECT FORMAT(GETDATE(), 'hh:mm tt')  -- → 02:35 PM
SELECT FORMAT(GETDATE(), 'HH:mm')     -- → 14:35
```

> `'yyyy/mm/dd HH:MM'` のように大文字小文字を間違えると、月と分の値が入れ替わるバグになるので注意が必要です。
> 

#### ② 数値の整形（カンマ区切り・パーセント・通貨）

```sql
SELECT FORMAT(1234567, '#,##0')    -- → 1,234,567
SELECT FORMAT(0.1234, 'P1')        -- → 12.3%
SELECT FORMAT(1234.5, 'C', 'ja')   -- → ¥1,235
```

#### ③ ゼロ埋め（桁揃え）

```sql
SELECT FORMAT(1,   '000')  -- → 001
SELECT FORMAT(12,  '000')  -- → 012
SELECT FORMAT(123, '000')  -- → 123
```

> IDや管理番号を桁数で揃えたいときに便利です。
> 

#### ④ ロケール指定（国ごとの表示切り替え）

```sql
SELECT FORMAT(1234567, 'N', 'ja')  -- → 1,234,567（日本）
SELECT FORMAT(1234567, 'N', 'de')  -- → 1.234.567（ドイツ）
SELECT FORMAT(1234567, 'C', 'en')  -- → $1,234,567.00（米ドル）
```

> 多言語対応のレポートで便利です。
> 

#### ⑤ 曜日・月名の取得

```sql
SELECT FORMAT(GETDATE(), 'dddd', 'ja')  -- → 月曜日
SELECT FORMAT(GETDATE(), 'MMMM', 'ja')  -- → 6月
SELECT FORMAT(GETDATE(), 'dddd', 'en')  -- → Monday
```

## 書式指定子について

FORMAT関数の第2引数には2種類の指定方法があります。

### 標準書式指定子（1文字で指定するショートカット）

よく使うパターンを1文字で呼び出せる。後ろに数字をつけると桁数を指定できます。

| 指定子 | 名前 | 例 | 結果 |
| --- | --- | --- | --- |
| `N` | Number（数値） | `FORMAT(1234567, 'N0')` | `1,234,567` |
| `C` | Currency（通貨） | `FORMAT(1234, 'C', 'ja')` | `¥1,234` |
| `P` | Percent（パーセント） | `FORMAT(0.1234, 'P1')` | `12.3%` |
| `F` | Fixed-point（小数点固定） | `FORMAT(3.14159, 'F2')` | `3.14` |
| `E` | Exponential（指数） | `FORMAT(12345678, 'E2')` | `1.23E+007` |
| `D` | Decimal（整数・ゼロ埋め） | `FORMAT(42, 'D5')` | `00042` |

```sql
SELECT FORMAT(1234567, 'N0')  -- → 1,234,567（小数点なし）
SELECT FORMAT(1234567, 'N2')  -- → 1,234,567.00（小数点2桁）
SELECT FORMAT(0.1234,  'P1')  -- → 12.3%（小数点1桁）
SELECT FORMAT(42,      'D5')  -- → 00042（5桁でゼロ埋め）
```

### カスタム書式（パターンを自分で組み立てる）

`'yyyy/MM/dd'` や `'#,##0'` のように、文字を組み合わせて細かく指定しましょう。

```sql
SELECT FORMAT(GETDATE(), 'yyyy/MM/dd HH:mm')  -- → 2026/07/01 14:35
SELECT FORMAT(1234567,   '#,##0')             -- → 1,234,567
SELECT FORMAT(-1234,     '(#,##0)')           -- → (1,234)
```

## ロケールについて

第3引数で「どの国・言語の表示ルールを使うか」を指定する。省略するとSQL Serverの設定言語が自動で使われます。

```sql
-- 数値の区切り文字が国によって異なる
SELECT FORMAT(1234567, 'N', 'ja') -- → 1,234,567（日本：カンマ区切り）
SELECT FORMAT(1234567, 'N', 'de') -- → 1.234.567（ドイツ：ピリオド区切り）

-- 通貨記号が変わる
SELECT FORMAT(1234, 'C', 'ja') -- → ¥1,234
SELECT FORMAT(1234, 'C', 'en-US') -- → $1,234.00
SELECT FORMAT(1234, 'C', 'en-GB') -- → £1,234.00

-- 曜日・月名の言語が変わる
SELECT FORMAT(GETDATE(), 'dddd', 'ja') -- → 月曜日
SELECT FORMAT(GETDATE(), 'dddd', 'en') -- → Monday
SELECT FORMAT(GETDATE(), 'dddd', 'fr') -- → lundi
```

よく使うロケール一覧：

| 指定値 | 言語・地域 |
| --- | --- |
| `ja` | 日本語 |
| `en-US` | 英語（アメリカ） |
| `en-GB` | 英語（イギリス） |
| `de` | ドイツ語 |
| `fr` | フランス語 |
| `zh-CN` | 中国語（簡体字） |

> 日本向けのシステムしか作らないなら基本省略でOKです。サーバーの言語設定が不安なときや多言語対応レポートでは明示的に指定しましょう。
>

## 注意点

| # | 内容 |
| --- | --- |
| ① | **パフォーマンスが遅い**：内部で.NETライブラリを呼ぶため、CONVERTやCASTより重い。大量データへの使用は避ける |
| ② | **戻り値はNVARCHAR**：計算や絞り込み条件には使えない |
| ③ | **SQL Server 2012以降のみ対応**：古い環境では動かない |
| ④ | **NULLを渡すとNULLが返る**：NULL対策が必要なら`ISNULL`や`COALESCE`と組み合わせる |
| ⑤ | **WHERE句・JOINのキーには絶対使わない**：パフォーマンス問題＋意図しない結果になる可能性あり |
| ⑥ | **CONVERTで代替できる場面では素直にCONVERTを使う**：FORMAT特有の機能が必要なときだけFORMATを使う |

```sql
-- NULLへの対策例
SELECT FORMAT(ISNULL(対象列, 0), '#,##0')

-- CONVERTで済む例（FORMATは不要）
SELECT CONVERT(varchar, GETDATE(), 111) -- → 2026/07/01
```

## 使い分けまとめ

| 用途 | 推奨 |
| --- | --- |
| 日付を好きなフォーマットで表示 | FORMAT |
| 曜日・月名をロケール指定で取得 | FORMAT |
| カンマ区切り・会計フォーマット | FORMAT |
| 高速な型変換 | CONVERT |
| WHERE句での日付絞り込み | CONVERT or CAST |
| JOINのキー | CONVERT or CAST |
