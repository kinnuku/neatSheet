# データ型を変換する
キーワード: CAST / CONVERT / TRY_CAST

> <strong>CAST() / CONVERT()とは？</strong>
> あるデータ型を別のデータ型に変換する関数です。
> ※CONVERTは、SQL Server特有の関数で日付や時刻などのフォーマットを指定することができます。

### １．使い方

基本的に細かい規則はないですが、 `DATE` に変換する場合は、 `VARCHAR` や `CHAR` 等の文字列でないと変換できません。
データ型については、以下でまとめています。

[データ型の基本](../06_基礎知識/01_データ型の基本.md) 

`CONVERT`  のフォーマットにはいろいろ種類がありますが、以下さえ覚えておけばOKです。

- <strong>111 ： 日本の日付形式（yyyy/mm/dd）</strong>
- <strong>112：ISOの日付形式（yyyymmdd）</strong>

詳しく気になる場合は、以下より確認してみてください。

[CAST および CONVERT (Transact-SQL) - SQL Server](https://learn.microsoft.com/ja-jp/sql/t-sql/functions/cast-and-convert-transact-sql?view=sql-server-ver17)

```sql
CAST(値 AS データ型)
CONVERT(データ型, 値, [フォーマット])

DECLARE @DATE_NUM AS NUMERIC = 20260401
DECLARE @DATE_DATE AS DATE = '2026-04-01'

CAST(@DATE_NUM AS DATE)
-- → エラーになる。（NUMERICをDATEに変換しようとしているため）

-- yyyymmdd形式からyyyy-mm-dd形式にしたい場合（CAST）
CAST(CAST(@DATE_NUM AS VARCHAR(8)) AS DATE)
-- → 2026-04-01

-- yyyymmdd形式からyyyy-mm-dd形式にしたい場合（CONVERT）
CONVERT(DATE, CAST(@DATE_NUM AS VARCHAR(8)))
-- → 2026-04-01

-- yyyy-mm-dd形式からyyyymmdd形式にしたい場合
CONVERT(CHAR(8), @DATE_DATE, 112)
-- → 20260401
```

`CAST` で変換できなかったら `NULL` を返したい場合は、 `TRY_CAST` を使用しましょう。

```sql
TRY_CAST('2026-13-45' AS DATE)
-- → NULL（存在しない日付なので NULL）

TRY_CAST('20260401' AS DATE)
-- → 2026-04-01
```

※ `TRY_CAST(@DATE_NUM AS DATE)` のように、NUMERIC → DATE など<strong>そもそも変換が許可されていない組み合わせ</strong>は、`TRY_CAST` でも NULL ではなくエラーになります。
